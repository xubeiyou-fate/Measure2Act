# Security policy

## Supported versions

Security fixes are applied to the latest `1.0.x` release line and the default
branch while this research package is maintained.

## Reporting a vulnerability

Use GitHub private vulnerability reporting when it is enabled for the public
repository. If that route is unavailable, contact the corresponding author at
`zhaotianyi@dlut.edu.cn` with the subject `Measure2Act security report`.

Do not include credentials, private repository links, restricted trajectory
records, identifiable aviation data, or unpublished model assets in a public
issue. Include the affected version, environment, minimal reproduction, and
impact assessment in the private report.

## Safety boundary

Measure2Act is retrospective research software, not certified aviation or
air-traffic-control software. A model-quality issue that could encourage
operational use outside the documented scope should also be reported privately.
